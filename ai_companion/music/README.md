# Music

Put songs here (MP3, M4A, OGG, FLAC, WAV, OPUS). Say "Rabbit, play a song"
and Rabbit plays a random one. The files are not stored in git; copy them to
the Pi directly, for example from a laptop:

    scp *.mp3 techknights@TechKnights:~/stg-make-a-thon-21/ai_companion/music/

Playback needs mpv: `sudo apt install mpv`.
